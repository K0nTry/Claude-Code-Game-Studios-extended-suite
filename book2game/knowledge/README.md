# `knowledge/` — Knowledge Artifacts

Contains structured knowledge models extracted from source text:
- `StyleDNA.json`: Character voice fingerprint and lexical profile
- `WorldMuncher.json`: World-model representation (locations, factions, relationships)
- `foreshadowing.json`: Narrative foreshadowing tracker across chapters
- `progress-state.json`: Session progress tracking

Each file is governed by its corresponding JSON Schema in `../schemas/`.
See `../roadmap.md` for integration phases.
