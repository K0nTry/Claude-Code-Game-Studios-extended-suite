# Game Engine Selection

## Επιλογή

- **Engine:** Godot 4.x (GDScript / C#)
- **Αιτιολόγηση:** Βασίστηκε στο είδος Adventure, άρα η Godot παρέχει εξαιρετική υποστήριξη 2D & lightweight 3D, με ελαφρύ footprint & ενσωματωμένο editor.

## Target Platforms

- PC (Windows, Linux, macOS)
- Mobile (Android, iOS)
- Web (HTML5)

## Game Studio MCP Integration

- **MCP Server:** Godot MCP Server
- **Agent:** godot-specialist, gdscript
- **Bridge Hooks:** Headless CLI execution, GUT unit tests, GDScript linter
