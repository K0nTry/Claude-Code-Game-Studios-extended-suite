# `views/` — Agent Projections

Contains per-agent projection views assembled from canon + derived artifacts.

- `projections/`: One subfolder per specialist agent (e.g., `narrative-director/`)
  - Each contains `IMMUTABLE_KERNEL.md`, `canon.projection.json`, `derived.projection.json`

Projections are self-contained views with immutable kernel headers proving source fidelity.
See `../standards/projection-template.md` for the template specification.
